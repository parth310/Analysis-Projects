# 📊 Loan Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing loan data to understand borrower behavior, loan distribution, and financial risk patterns.  
The dashboard provides insights that help financial institutions evaluate loan performance and identify risk factors.

The analysis highlights trends in loan amounts, borrower demographics, credit scores, and default patterns using an interactive Power BI dashboard.

## 🎯 Objectives
The main objectives of this project are:

- Analyze loan distribution by different purposes
- Understand borrower demographics and financial profiles
- Identify patterns related to loan defaults
- Study the relationship between credit score and loan amount
- Provide insights to support better lending decisions

---

## 📊 Key Insights

### 1️⃣ Loan Distribution by Purpose
The dashboard shows how loan amounts are distributed across different loan purposes such as:
- Home loans
- Business loans
- Education loans
- Personal loans

This helps identify which sectors receive the highest loan funding.

### 2️⃣ Default Rate Analysis
The project analyzes default patterns based on borrower characteristics like:
- Employment type
- Credit score
- Income level

This helps financial institutions identify high-risk borrowers.

### 3️⃣ Borrower Demographics
The dashboard analyzes borrower demographics including:
- Age group
- Marital status
- Education level
- Employment status

This helps understand the profile of loan applicants.

### 4️⃣ Credit Score vs Loan Amount
The analysis shows how loan amounts vary across different credit score categories.  
This insight helps determine how creditworthiness impacts lending decisions.

### 5️⃣ Yearly Loan Trends
Loan distribution over multiple years helps identify:
- Growth trends
- Decline periods
- Financial lending patterns

## 🛠 Tools & Technologies Used

- **Power BI** – Data visualization and dashboard creation
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – Calculated measures and metrics
- **Excel / CSV Dataset** – Data source

---

## 📂 Dataset Features

The dataset used in this project includes the following attributes:

| Column | Description |
|------|-------------|
| Loan Amount | Amount borrowed by the applicant |
| Loan Purpose | Purpose of the loan |
| Credit Score | Credit rating of the borrower |
| Income Level | Borrower's income category |
| Employment Type | Employment status |
| Marital Status | Marital status of the applicant |
| Age Group | Age category |
| Education Level | Educational qualification |
| Default Status | Indicates whether the loan defaulted |
